# CiberHispanos

Portal independiente de información y orientación ante ciberacoso y otras formas de violencia o abuso digital.

## Principios
- Utilidad práctica para personas de cualquier edad.
- Rutas específicas para personas afectadas, personas cercanas y profesionales.
- Privacidad por diseño: el orientador y el buscador funcionan en el navegador.
- Fuentes oficiales o primarias para teléfonos, procedimientos, legislación y recursos críticos.
- No sustituye emergencias, atención sanitaria, asesoramiento jurídico, servicios sociales ni autoridades.
- Código portable: HTML, CSS y JavaScript estándar, sin dependencia esencial de GitHub Pages.

## Estructura
- `index.html`: entrada principal.
- `refugio.html`: acceso rápido cuando la persona necesita ordenar los primeros pasos.
- `orientador.html`: orientación privada mediante preguntas cerradas.
- `buscar.html`: buscador local de situaciones.
- `centro-ayuda.html`: catálogo de problemas y rutas.
- `recursos.html`: recursos de ayuda externos.
- `casos/`: rutas prácticas por situaciones.
- `guias/`: guías temáticas.
- `assets/`: estilos y JavaScript.

## Mantenimiento editorial
Toda información crítica debe incluir una fuente verificable y revisarse periódicamente. Si un dato no puede confirmarse, no debe presentarse como hecho. Los flujos de plataformas pueden cambiar y deben comprobarse antes de publicar instrucciones paso a paso.

## Desarrollo local
No requiere compilación. Puede servirse con cualquier servidor HTTP estático. Los enlaces internos son relativos para facilitar migración a cualquier hosting.

## Privacidad
No añadir analítica, formularios de casos, cuentas o servicios de terceros sin una revisión específica de privacidad, seguridad y necesidad.
